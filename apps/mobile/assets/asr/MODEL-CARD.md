# ReazonSpeech K2 v2 mobile ASR

Source: https://huggingface.co/reazon-research/reazonspeech-k2-v2

This bundle contains the Japanese character-based RNN-T Zipformer model used by
Kotoba Beacon Native, with the encoder and joiner in INT8 form. It is executed
through sherpa-onnx 1.13.3 and ONNX Runtime 1.26.0 on Mobile CPU.
