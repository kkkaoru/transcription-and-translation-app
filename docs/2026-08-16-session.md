## 3. Shipped but not actually running (seven)

These are the “we implemented it, then found it was not on the path”
fixes from this day. Each one looked done until a contract, a
measurement, or a binary search proved otherwise.

1. **Compare dropped `leftContext` on empty previous captions**
   (`44dbf20`). A truthy check omitted the key. Worker then skipped
   Zenz as `empty-left-context`. Contract 5 exists because of this.
2. **Max-iter always returned the dictionary baseline** (`541e686`).
   Plan 1 returns the last constrained candidate. Plan 3 now does too.
3. **`usedCompletion` meant “text ≠ baseline”** (`44997cf`). That hid
   “Zenz ran and agreed”. It now means the completion was inspected
   (`iterations > 0`).
4. **1-best compatibility faked `FALLBACK`** (`b91c8e1`).
   `azookey_convert_n_best` is now required ABI. Dead `unpackResult`
   deleted. Status bits: OK=0, FALLBACK=specified dict unused,
   INVALID_UTF8, INVALID_ARGUMENT.
5. **Lazy converter did not forward `openLattice`** (`ea9525e`). Wasm
   had the export; the wrapper dropped it. Contract 3 exists because
   of this. Local `check:all` also dropped the post-build
   `assets:verify` until `bd971fc` (contract 4).

   download (600 MB / 461 MB) then fail
   `gguf_init_from_reader` tensor offset mismatch. Removed from the
   catalog. 7B stays; it loads.
7. **`bun run build:app` pruned the Rust debug cache** (`f05242f`).
   Next `check:all` paid 314 s to rebuild. After the 07:10 install,
   `apps/desktop/src-tauri/target` is 6.2 G (debug 3.9 G still
